# 路面病害信息组织与养护决策：HTML 文献汇报

基于 nature-paper2ppt 规范及用户确认的16页制作执行稿制作，采用用户提供的深大红模板框架。

## 下载与查看

1. 点击 [下载 HTML 全套 ZIP](./road_review_html_final.zip?raw=true)，在 GitHub 文件页可使用 Download raw file 下载
2. 解压到电脑文件夹，例如 D:\文献汇报
3. 用 Edge 或 Chrome 打开 index.html；pages 文件夹含16个独立页面
4. 页面可展开汇报备注，点击论文原图可放大，左右方向键可切换阅读

[整套页面总览](./road_review_html_contact.jpg)

## 交付范围

- 本次仅交付 HTML、原图素材、页面总览、来源清单与检查记录
- 未生成 SVG 或 PPTX，未进行 Microsoft PowerPoint 转形测试
- 模板实测为756×425.25pt，16∶9
- 论文图像完整内嵌，HTML可离线打开
- 中文字体优先微软雅黑，英文与数字优先Arial；不同系统字体替换可能影响换行
- Chromium逐页检查未发现页面边界溢出、文字相互重叠、页脚侵占或损坏图片

## 核心文献

1. A Semantic Digital Twinning Approach for the Management of Road Distress Data. DOI: 10.5194/isprs-annals-X-4-W5-2024-49-2024
2. Context-aware knowledge graph reasoning for road maintenance decision-making. DOI: 10.1016/j.aei.2026.104618

页面明确区分论文方法与结果、本次评析和对本人研究的建议。原论文PDF与用户上传模板不单独收录于此交付目录。
